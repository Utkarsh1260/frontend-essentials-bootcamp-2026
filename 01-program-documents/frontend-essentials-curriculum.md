# Frontend Essentials Bootcamp 2026

## Curriculum Document

### 1. Program Overview

Frontend Essentials Bootcamp is a beginner-friendly training program designed to introduce students to the fundamentals of frontend web development. The program focuses on building a strong foundation in HTML, CSS, Responsive Web Design, and JavaScript basics through practical learning and guided implementation.

---

### 2. Program Duration

* Total Sessions: 8
* Session Frequency: 1 Session per Week
* Session Duration: 3 Hours
* Total Learning Hours: 24 Hours

---

### 3. Target Audience

This bootcamp is intended for:

* Beginners with little or no prior web development experience
* Students interested in learning frontend development
* Learners seeking hands-on exposure to website development fundamentals

---

### 4. Learning Objectives

The primary objectives of this bootcamp are to enable participants to:

* Understand the fundamentals of web development
* Create structured web pages using HTML
* Design and style web interfaces using CSS
* Build responsive layouts for various screen sizes
* Apply JavaScript fundamentals to add basic interactivity
* Develop static frontend projects
* Understand frontend development best practices

---

### 5. Learning Outcomes

Upon successful completion of the bootcamp, participants will be able to:

* Build structured and accessible web pages
* Create visually appealing user interfaces
* Develop responsive website layouts
* Implement basic interactive features using JavaScript
* Organize and present frontend projects professionally
* Continue their learning journey in frontend development with confidence

---

### 6. Technologies Covered

* HTML5
* CSS3
* Responsive Web Design
* JavaScript (Fundamentals)
* GitHub

---

### 7. Teaching Methodology

The bootcamp will be conducted through:

* Live Interactive Sessions
* Guided Demonstrations
* Hands-on Coding Practice
* Practical Implementation Exercises
* Discussion and Doubt-Clearing Sessions

Additional learning resources, practice materials, announcements, and relevant updates may be shared through the designated communication channels during the course of the bootcamp.

---

### 8. Assessment & Engagement Activities

Participant engagement may include:

* Interactive Discussions
* Practice Exercises
* Coding Activities
* Knowledge Checks and Quizzes
* Mini Challenges
* Project-Based Tasks

The exact activities may vary depending on participant progress and learning requirements.

---

### 9. Final Project

Participants will work on a frontend project that incorporates the concepts covered throughout the bootcamp, including HTML, CSS, responsive design principles, and JavaScript fundamentals.

---

### 10. Completion

Participants who actively engage in the bootcamp and complete the learning activities will have developed a foundational understanding of frontend web development and the ability to create responsive static websites independently.
