# Frontend Essentials Bootcamp 2026

## Detailed Syllabus

### Module 1: HTML Foundations

#### Session 1 – Introduction to Web Development & HTML Basics

Topics Covered:

* Introduction to Frontend Development
* Understanding How Websites Work
* HTML Document Structure
* Headings and Paragraphs
* Hyperlinks
* Images
* Ordered and Unordered Lists

Learning Outcome:

* Create and structure a basic web page using HTML.

---

#### Session 2 – Advanced HTML & Forms

Topics Covered:

* Tables
* Forms and Input Elements
* Labels and Form Controls
* Semantic HTML Elements
* Audio and Video Integration
* Embedding Content using iframe

Learning Outcome:

* Develop structured and user-friendly web pages using advanced HTML elements.

---

### Module 2: CSS & Responsive Web Design

#### Session 3 – CSS Fundamentals

Topics Covered:

* Introduction to CSS
* CSS Syntax and Selectors
* Colors and Backgrounds
* Typography and Text Styling
* Borders and Spacing
* CSS Box Model

Learning Outcome:

* Apply styling and visual enhancements to web pages using CSS.

---

#### Session 4 – Layout Design using CSS

Topics Covered:

* CSS Display Properties
* Flexbox Fundamentals
* Navigation Bar Design
* Card Components
* Section-Based Layouts
* Footer Design

Learning Outcome:

* Build structured and visually organized webpage layouts.

---

#### Session 5 – Responsive Web Design

Topics Covered:

* Responsive Design Principles
* Media Queries
* Mobile-First Development Approach
* Responsive Components
* Responsive Layout Techniques

Learning Outcome:

* Create websites that adapt effectively across different screen sizes and devices.

---

### Module 3: JavaScript Fundamentals

#### Session 6 – JavaScript Basics

Topics Covered:

* Introduction to JavaScript
* Variables and Constants
* Data Types
* Operators
* Conditional Statements
* Loops

Learning Outcome:

* Write basic JavaScript programs and implement simple decision-making logic.

---

#### Session 7 – JavaScript Interactivity & DOM Basics

Topics Covered:

* Functions
* Arrays
* Introduction to the DOM
* DOM Selection and Manipulation
* Events and Event Handling
* Interactive Web Elements

Learning Outcome:

* Add basic interactivity and dynamic behavior to web pages.

---

### Module 4: Project Development & Review

#### Practice YourSelf – Final Project, Revision & Showcase

Topics Covered:

* Responsive Static Website Development
* Application of HTML, CSS, and JavaScript Concepts
* Project Review
* Doubt Clearing Session
* Project Showcase and Discussion

Learning Outcome:

* Build and present a complete responsive static website by applying concepts learned throughout the bootcamp.

---

## Assessment & Practice Activities

Throughout the bootcamp, participants may engage in:

* Hands-on Coding Exercises
* Practice Questions
* Interactive Activities
* Live Quizzes
* Mini Challenges
* Guided Assignments
* Project-Based Learning Tasks

The nature and frequency of activities may vary based on participant progress and learning requirements.
